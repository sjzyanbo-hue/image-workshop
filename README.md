# 图片工坊 · 拼接 / 分离

一个**纯前端、零依赖、完全离线**的图片拼接与切分工具。单个 HTML 文件，双击即用，所有处理都在本机浏览器内通过 Canvas 完成 —— 不联网、不上传、不依赖任何外部库。

## 功能

### 拼接（多合一）
- 布局：横向一排 / 纵向一列 / 网格矩阵 / 自动铺排
- 尺寸统一：按高 / 按宽 / 按单元格对齐，可选以最小、最大或第一张为基准
- 单元格填充：完整留白 / 填满裁切 / 拉伸
- 排版：间距、外边距、圆角、背景色 / 透明
- 缩略图条：拖拽排序、旋转、复制、删除
- 导出 PNG / JPG（可调质量）

### 分离（一变多）
- 来源：选择整个文件夹（按文件名自然排序）或逐张添加，可混用、可拖拽改序
- 切割模式：等分网格（行×列）/ 横切 N 份 / 竖切 N 份 / 按固定尺寸切块 / 自定义切线（每张图独立、可拖动）
- 多张图连续编号，8 种编号顺序可选
- 导出：打包 ZIP（内置打包器，上百张也只下一个包）或逐张下载

## 使用

直接用浏览器打开 `图片工坊-拼接分离工具.html` 即可。也支持把图片拖进窗口或 `Ctrl+V` 粘贴。

## 代码结构（供迭代参考）

单文件，`<style>` + `<script>` 内联。核心逻辑：

| 区块 | 说明 |
|------|------|
| `M`（状态对象） | 拼接模式的全部参数与图片列表 |
| `computeMerge()` | 根据布局/尺寸/排版算出每张图的位置 |
| `mRender()` | 将计算结果绘制到 `#mergeCanvas` |
| `renderStrip()` | 拼接缩略图条（拖拽/旋转/复制/删除） |
| `S`（状态对象） | 分离模式的图片列表与切割参数 |
| `cutFractions()` / `computeSlices()` | 计算切割比例与各切块矩形 |
| `ORD` + `orderPairs()` | 8 种编号顺序的统一实现（拼接置入顺序与分离编号顺序共用） |
| `buildZip()` | 内置轻量 ZIP 打包器（store 模式 + 手写 CRC32，无外部依赖） |

### 已知特性 / 待改进
- 状态全部在内存中，图片以 dataURL 保存；图多或图大时较吃内存。
- 刷新页面会丢失全部内容（无持久化）。
- ZIP 仅存储不压缩（PNG/JPG 已是压缩格式，无需再压）。
